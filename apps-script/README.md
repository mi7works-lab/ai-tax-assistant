# 架電KPIダッシュボード（Google スプレッドシート版）

生ログ（架電リスト）から、架電KPIダッシュボードを自動生成する Google Apps Script です。
React版（`src/Dashboard.tsx`）と同じ集計ロジック・色分けをスプレッドシート上で再現します。

## セットアップ

1. 対象のスプレッドシートを開く
2. **拡張機能 > Apps Script** を開く
3. `KadenDashboard.gs` の中身を全文貼り付けて保存
4. スプレッドシートに戻り、上部メニュー **架電ダッシュボード > ① 集計を更新 / 再構築** を実行
   - 初回のみ Google の権限承認が必要です
5. `ダッシュボード` シートと `目標` シートが自動生成されます

## できること

- **種別ドロップダウン**（全体／サービス種別）— `ダッシュボード!C3`
- **対象月**（データに含まれる月を自動列挙）— `ダッシュボード!C4`。6月・7月…を選んで切替
- **期間モード**（月間／週次／任意期間）— `ダッシュボード!C5`
  - **週次**: `C6` のプルダウンで週（第N週）を選択。対象月に応じて日付は自動計算
  - **任意期間**: `C7`（開始日）〜 `E7`（終了日）を入力
- いずれの切り替えも数式で**即再集計**（メニュー実行は不要）

### 月またぎ（7月以降）について

- データに含まれる全ての月の週区分を生成して保持します
- **対象月ドロップダウン**で過去月も含めていつでも切替可能（数式連動で即時）
- 新しい月の架電データを貼ったら、メニュー **① 集計を更新 / 再構築** を一度実行すれば、
  その月が対象月ドロップダウンに追加されます（既存月の切替は再実行不要）
- **サマリー表（ファネル分解）** — 架電件数 → 接触数・接触率 → 担当接触数・受付突破率 → アポ数・接触→アポ率・アポ率 → 目標・進捗・判定
  - **接触数** ＝ 誰かと話せた架電（受付対応：… または 担当接触：…。不通・現アナ以外）
  - **接触率** ＝ 接触数 ÷ 架電件数（電話がつながり人が出た割合。番号品質・架電時間帯）
  - **担当接触数** ＝ 担当者本人と話せた架電（担当接触：… 7〜10）
  - **受付突破率** ＝ 担当接触数 ÷ 接触数（受付を突破して担当に到達できた割合）
  - **接触→アポ率** ＝ アポ数 ÷ 担当接触数（担当クロージング。低いセルは黄ハイライト）
  - ※各列ヘッダーにはセルのコメント（メモ）で定義を記載
- **目標進捗の可視化（3通り）**
  - **目標進捗 %**：架電件数 ÷ 月間架電目標
  - **進捗バー**：セル内バーチャート（SPARKLINE）で達成度を直感的に表示
  - **判定バッジ**：達成（緑）／要注意／未達（赤）
- **おすすめの打ち手（Next Action）** — ファネルの最弱点を自動診断して提示
  - メンバー別「打ち手」列：受付突破↑／担当トーク↑／架電量↑ など、効く順に1つ提示
  - ※接触率（リスト品質・架電時間帯）は外的要因のため打ち手の対象外
  - **ルールは `目標` シートの「おすすめ打ち手ルール」表（F:I列）で編集可能**
    - **反映されるのは H列:閾値 と I列:打ち手の文言のみ**（変更するとダッシュボードに即反映）
    - F列:優先・G列:条件 は説明用ラベルで、編集しても判定ロジック（指標・順序）は変わりません
    - この表は一度作成後は再構築しても上書きされません（編集を保持）
    - 目標シートには「編集ガイド」も記載（どこを編集すると反映されるかの解説）
- **未達(NA)の自動色分け** — アポ0／アポ率が目標未満＝赤、接触→アポ率が低い＝黄
- **達成ペース（ダッシュボード下部）** — 累積実績と目標ペース直線を重ねたバーンアップ折れ線（架電・アポの2本）
  - **選択期間内**の累積で表示（期間モード＝月間/週次/任意期間に連動）
  - 目標ペースは暦日ベースの直線（1日あたり＝チーム全体の月間目標÷月日数）
  - グラフの元になる日次集計表は隠しシート(_集計データ R:X列)に作成し、画面には出しません
- **メンバー別の構成比（ダッシュボード下部）** — アポ数・架電数の割合を円グラフで表示（誰が実績の多くを占めるか）
- 上記グラフ・推移はすべて 種別／対象月／期間モード のプルダウンに連動
- **KPI** — 総架電数・担当接触率・総アポ数・平均アポ率
- **合計 / 平均** 行

## 週の区切りルール（自動生成）

「**1日始まり・月〜日区切り・月末締め**」で対象月の週を自動生成します。
例）2026年6月（1日が月曜）：

| 週 | 期間 |
| --- | --- |
| 第1週 | 6/1 〜 6/7 |
| 第2週 | 6/8 〜 6/14 |
| 第3週 | 6/15 〜 6/21 |
| 第4週 | 6/22 〜 6/28 |
| 第5週 | 6/29 〜 6/30（月末締め） |

対象月はデータ内の最新の架電日から自動判定します。

## 集計の定義

- **種別＝シートタブ名**。名前に「リスト」を含むタブ（例：`リスト（介護）`、`リスト（名刺）`）を全て読み、
  タブ名の `（ ）` 内を種別として扱う（`リスト（介護）` → 種別「介護」）
- 各タブの 1法人=1行の生ログから、1〜4回目の `架電日`/`架電結果` を 1架電=1行 に展開（隠しシート `_集計データ`）
- `架電担当者` × `種別（タブ名）` × `架電日` で集計
- **架電件数** = 架電日が入っている回数（日付ベース集計のため、架電日が空の行は対象外）
- **担当接触数** = 結果が `CONTACT_KEYWORDS`（既定 `担当接触`）を含む回数 → 選択肢 7〜10
- **アポ数** = 結果が `APPT_KEYWORDS`（既定 `アポ`）を含む回数 → 選択肢 10「担当接触：アポ」

架電結果の選択肢（例）：`1_不通` / `2_現アナ` / `3〜6_受付対応：…` / `7〜10_担当接触：…`（10=アポ）。
これらは既定キーワードでそのまま正しく分類されます。

## 調整ポイント（スクリプト先頭の `CONFIG`）

| 項目 | 説明 |
| --- | --- |
| `RAW_SHEET` | 生ログのシート名。空欄なら「架電担当者」列を含むシートを自動検出 |
| `CONTACT_KEYWORDS` | 「担当接触」とみなす架電結果の語（部分一致）。自社の選択肢に合わせて変更 |
| `APPT_KEYWORDS` | 「アポ」とみなす架電結果の語（部分一致） |
| `CONTACT_RATE_BENCH` | 担当接触率の警告基準（既定 0.2 = 20%） |

`目標` シートはメンバーごとの稼働数・月間架電目標・目標アポ率を手で編集できます。

## 自動更新（毎日 6:00 / 20:00）

メニュー **架電ダッシュボード > ② 自動更新を設定（毎日 6:00 / 20:00）** を1回実行すると、
時刻トリガーが登録され、毎日 6時台・20時台に自動で集計が更新されます（手動実行不要）。

- 解除は **自動更新を解除** から
- 実行時刻はApps Scriptプロジェクトのタイムゾーンに従います。**プロジェクト設定 > タイムゾーン を「(GMT+09:00) 東京」** にしてください
- 初回設定時に時刻トリガーの承認を求められます

## 毎月の更新

生ログを更新（貼り付け）したら、メニュー **① 集計を更新 / 再構築** を押すだけ。
種別ドロップダウンの切り替えは数式連動なので、押し直し不要です。
