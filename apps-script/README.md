# 架電KPIダッシュボード（Google スプレッドシート版）

生ログ（架電リスト）から、架電KPIダッシュボードを自動生成する Google Apps Script です。
React版（`src/Dashboard.tsx`）と同じ集計ロジック・色分けをスプレッドシート上で再現します。

## セットアップ

1. 対象のスプレッドシートを開く
2. **拡張機能 > Apps Script** を開く
3. `KadenDashboard.gs` の中身を全文貼り付けて保存
4. スプレッドシートに戻り、上部メニュー **架電ダッシュボード > ① 集計を更新 / 再構築** を実行
   - 初回のみ Google の権限承認が必要です
5. `ダッシュボード` シートと `目標` シートが自動生成されます

## できること

- **種別ドロップダウン**（全体／サービス種別）— `ダッシュボード!C3`
- **期間モード**（月間／週次／任意期間）— `ダッシュボード!C4`
  - **週次**: `C5` のプルダウンで週を選択
  - **任意期間**: `C6`（開始日）〜 `E6`（終了日）を入力
- いずれの切り替えも数式で**即再集計**（メニュー実行は不要）
- **サマリー表** — 架電件数・担当接触数・担当接触率・アポ数・接触→アポ率・アポ率・目標・進捗・判定
- **未達(NA)の自動色分け** — アポ0／アポ率が目標未満＝赤、担当接触率が基準未満＝黄
- **KPI** — 総架電数・担当接触率・総アポ数・平均アポ率
- **合計 / 平均** 行

## 週の区切りルール（自動生成）

「**1日始まり・月〜日区切り・月末締め**」で対象月の週を自動生成します。
例）2026年6月（1日が月曜）：

| 週 | 期間 |
| --- | --- |
| 第1週 | 6/1 〜 6/7 |
| 第2週 | 6/8 〜 6/14 |
| 第3週 | 6/15 〜 6/21 |
| 第4週 | 6/22 〜 6/28 |
| 第5週 | 6/29 〜 6/30（月末締め） |

対象月はデータ内の最新の架電日から自動判定します。

## 集計の定義

- 1法人=1行の生ログから、1〜4回目の `架電日`/`架電結果` を 1架電=1行 に展開（隠しシート `_集計データ`）
- `架電担当者` × `サービス種別一覧` × `架電日` で集計
- **架電件数** = 架電日が入っている回数（日付ベース集計のため、架電日が空の行は対象外）
- **担当接触数** = 結果が `CONTACT_KEYWORDS`（既定 `担当接触`）を含む回数 → 選択肢 7〜10
- **アポ数** = 結果が `APPT_KEYWORDS`（既定 `アポ`）を含む回数 → 選択肢 10「担当接触：アポ」

架電結果の選択肢（例）：`1_不通` / `2_現アナ` / `3〜6_受付対応：…` / `7〜10_担当接触：…`（10=アポ）。
これらは既定キーワードでそのまま正しく分類されます。

## 調整ポイント（スクリプト先頭の `CONFIG`）

| 項目 | 説明 |
| --- | --- |
| `RAW_SHEET` | 生ログのシート名。空欄なら「架電担当者」列を含むシートを自動検出 |
| `CONTACT_KEYWORDS` | 「担当接触」とみなす架電結果の語（部分一致）。自社の選択肢に合わせて変更 |
| `APPT_KEYWORDS` | 「アポ」とみなす架電結果の語（部分一致） |
| `CONTACT_RATE_BENCH` | 担当接触率の警告基準（既定 0.2 = 20%） |

`目標` シートはメンバーごとの稼働数・月間架電目標・目標アポ率を手で編集できます。

## 毎月の更新

生ログを更新（貼り付け）したら、メニュー **① 集計を更新 / 再構築** を押すだけ。
種別ドロップダウンの切り替えは数式連動なので、押し直し不要です。
